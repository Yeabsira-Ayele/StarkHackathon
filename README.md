## Try this (about 3 minutes)

1. **Home:** scroll through "how it works" and the impact numbers.
2. **Discover Causes:** search, filter by sector, and open a cause.
3. **Voice:** click the orange mic or "VOXIDE", allow the microphone, and say:
   - "Find campaigns for schools"
   - "Open the first cause"
   - "How much has been raised?"
   - "Start a fundraiser called School Library, education, goal 50,000 birr" (the form opens pre-filled)
4. **Donate:** open a cause, make a test pledge, and download the certificate.
5. **Foundation account:** create a fundraiser and see it under "My fundraisers".
6. **Admin account:** approve a pending fundraiser.

## Notes

- Voice works in English. Amharic voice is limited.
- The backend runs on a free plan, so the first load can take up to a minute.
- If the voice assistant says it is taking a break, please see the demo video above.
