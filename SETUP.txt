LEWEGENE - PERSON 1 UPDATE (phone + OTP + password)

1. Unzip this folder.
2. Copy everything inside it into your BACKEND folder (the one with server.js).
   Say YES to replace files.
3. In your .env file, make sure these two lines exist:
      OTP_DEV_ECHO=true
      DISABLE_RATE_LIMIT=true
4. Clear the old test accounts (one time only). In the terminal:
      node scripts/reset-auth-data.js --yes
5. Start the server:   npm run dev
6. In a second terminal:   node scripts/smoke-test.js
   Every line should say PASS.
