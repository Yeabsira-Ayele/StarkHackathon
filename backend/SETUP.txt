StarkHackathon full-stack local setup
=====================================

Requirements
- Node.js 18 or newer
- MongoDB running locally, or a MongoDB connection string

Backend
1. From the repository root, run: cd backend
2. Install backend dependencies: npm ci
3. Copy .env.example to .env and set MONGO_URI and a private JWT_SECRET
4. For local OTP testing only, add OTP_DEV_ECHO=true to backend/.env.
   The signup code is returned to the frontend only when this setting is enabled.
5. Start the API: npm run dev

Frontend
1. In a second terminal, return to the repository root.
2. Install frontend dependencies if needed: npm ci
3. Start Vite: npm run dev
4. Open http://localhost:3000

The frontend calls the API at http://localhost:5000/api by default.
For other deployments, set VITE_API_BASE_URL in the frontend environment.
Do not enable OTP_DEV_ECHO or DISABLE_RATE_LIMIT in production.
